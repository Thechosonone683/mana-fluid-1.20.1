## 📖 简介 | Description

**English:**
Botania Mana Fluid is an addon for the Botania mod which implements a **mana fluid** into Minecraft. It also modifies Botania's mana pools to interact with buckets and pipes from other Forge mods, allowing you to move mana around using fluid systems from mods like Thermal Series, Mekanism, and more.

**中文：**
Botania Mana Fluid 是植物魔法（Botania）的一个附属模组，它在 Minecraft 中实现了**魔力流体**。该模组还修改了植物魔法的魔力池，使其能够与其他 Forge 模组的桶和管道系统交互，从而让你可以使用热力系列、通用机械等模组的流体系统来运输魔力。

---

## ✨ 功能特点 | Features

- **Mana Fluid / 魔力流体** - Placeable mana liquid with custom textures and fog effects
  可放置的魔力液体，具有自定义纹理和雾效

- **Bucket Support / 桶支持** - Fill and empty mana using buckets
  使用桶来盛放和倾倒魔力

- **Pipe Compatibility / 管道兼容** - Connect mana pools to fluid pipes from other mods
  将魔力池连接到其他模组的流体管道

- **Fluid Interactions / 流体交互** - Mana fluid reacts with lava to create resources
  魔力流体与熔岩交互可生成资源
